# Le Gourmet - Professional Luxury Restaurant Website

A fully responsive, professional multi-page style single-page restaurant website built using HTML5, CSS3, JavaScript, and Bootstrap 5.

## Features Included:
1. **Index.html**: Main layout featuring Navbar, Hero Section, Menu, About Us, and Table Reservation with working Unsplash photography.
2. **Style.css**: Luxury dark-and-gold aesthetic with custom typography (`Cormorant Garamond` and `Montserrat`), card hover effects, and responsive design.
3. **Script.js**: Client-side interactive menu filtering (Starters, Mains, Desserts, Drinks) and table reservation form handling with confirmation toast alerts.

## How to Run:
1. Unzip the downloaded archive.
2. Open `index.html` in any modern web browser or live server.
